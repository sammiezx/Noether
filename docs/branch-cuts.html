For the imaginary power $f=z^{i\alpha}$, $|f|=e^{-\alpha\theta}$ — so the modulus jumps across the cut by $e^{2\pi\alpha}$, and one full loop around the branch point multiplies $f$ by $e^{-2\pi\alpha}$.
