α — carries e−iω′x, only damps if tipped into the lower half (−Im).
β — carries e+iω′x, only damps if tipped into the upper half (+Im).
The floor is the complex x-plane (Re →, Im is depth); the height is the integrand’s value along each contour. At φ = 0 both waves ride the real axis with constant amplitude — they never die, so the integrals diverge. Rotate, and each wave dives toward its own half-plane and damps to zero (the dashed line is its envelope). They must go opposite ways. As they swing around the branch point at x = 0, α’s wave grows by e+φω/κ and β’s shrinks by e−φω/κ — that height gap, squared, is e−2πω/κ.
