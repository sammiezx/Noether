RIEMANN SURFACE

THE SPIRAL STAIRCASE OF A MULTIVALUED FUNCTION
f(z) = ln z
height = the value · one loop around 0 = next floor
one CCW loop changes the value by
+2π (climb one floor)
Read it: the central pole is the branch point z = 0. The colored ramp is the function’s value plotted as height. Walk the bead once around the pole and it does not come back to where it started — it lands one floor up. That “extra floor” is exactly what multivalued means. The vertical wall is the branch cut: the cliff between floors that you only see if you try to flatten the staircase into one sheet.
